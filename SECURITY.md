# Security

Please report security problems privately, through
[GitHub's private vulnerability reporting](https://github.com/lucataco/cloudex/security/advisories/new),
not in a public issue or with `cloudex feedback` (which files public issues).

Include what an attacker can do, and the steps to show it. You'll get an answer within a few days.
Fixes ship in a new release; `cloudex update` installs it and updates your deployment.
